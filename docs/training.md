# Training Notes

The first public release is inference-first. The training notebooks remain the source of truth for retraining experiments:

- `notebooks/ImageClassifier.ipynb`
- `notebooks/SquareAnalyzer_MaxAccuracy.ipynb`
- `notebooks/AtlasAnalyzer_NonCSV_MaxAccuracy.ipynb`
- `notebooks/AtlasAnalyzer_MaxAccuracy.ipynb`
- `notebooks/AtlasPrerecognition.ipynb`

## Expected Data Shape

Classifier training expects folders corresponding to image types:

- `Atlas_All`
- `Square_All`
- `Protein_All`
- `Other_All`

Square analyzer labels should include:

- image identifier column, such as `Image Name`
- `Tags`
- `Rating`

Atlas analyzer labels should include:

- `combined_key`
- `Tags`
- `Rating`

Atlas-with-CSV training also expects an atlas summary table, usually generated by atlas prerecognition, with image identifiers and columns such as:

- `visible_square_count`
- `good_square_count`
- `non_uniform_square_count`
- `cracked_square_count`
- `bad_size_square_count`
- `atlas_quality_score`

Fraction features are derived during preprocessing.

## Reproducibility

The notebooks use fixed seeds, ResNet18 backbones, ImageNet normalization, and saved validation-tuned thresholds. If retraining, publish the resulting:

- model state
- `label_mappings.json`
- `thresholds.json`
- `best_model_metadata.json`
- `tabular_preprocessing.json` for atlas-with-CSV models

## Future Package Training Support

Training can be added later as optional modules under an extra such as `cryoemdoc[train]`. That work should include tests, documented dataset schemas, and versioned model metadata before being presented as a stable API.
